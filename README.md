## 🚀 Featured Projects

### 🤖 AI, Agents & Data

| Project | What it does | Stack |
|---|---|---|
| **[Footnote](https://github.com/ArshvirSk/Footnote)** | Managed **SEO + AEO/GEO platform** that tracks how brands show up in AI answers and Google. Multi-engine collection across OpenAI, Gemini, Perplexity, xAI and Anthropic; an LLM judge gated on a 40-case golden set; technical audit with per-AI-crawler `robots.txt` and JSON-LD checks; PR-ready dev briefs. | Next.js · FastAPI · LangGraph · Arq · Neon (pgvector, RLS) |
| **[PANCH](https://github.com/ArshvirSk/PANCH)** | **AI arbitration** for small cross-border disputes, built for the AWS *Zero to Shipped* hackathon. Three judges from different model families rule on blinded records, cross-examine, and escalate to a human; every step lands in a **SHA-256 hash-chained ledger** you can verify. [Live](https://main.d1hm3x5hny8fjb.amplifyapp.com) | AWS Bedrock · Step Functions · Lambda · DynamoDB · CDK |
| **[SIM-OPS](https://github.com/ArshvirSk/SIM-OPS)** | Autonomous **churn-prevention** platform. Random Forest churn/CLV model (>85% accuracy) feeding Monitoring → Prediction → Decision → Action agents that trigger Slack / Jira / email / Twilio workflows. [Demo](https://sim-ops-demo.vercel.app) | Next.js 14 · LangChain · Scikit-learn · Supabase |
| **[RegLens](https://github.com/ArshvirSk/RegLens)** | *(In progress)* Cited, temporally-aware **RAG over Indian banking regulation** (RBI / SEBI) and bank filings. Foundations done: corpus manifest, robots-aware fetcher, tracing, CI. | Python · FastAPI · Docker |
| **[TalentRank AI](https://github.com/ArshvirSk/TalentRank-AI)** | 8-stage **candidate ranking pipeline** for the Redrob India Runs Data & AI Challenge, running CPU-only and offline. FAISS retrieval over `bge-small-en-v1.5` embeddings. *Team project; I built the data engineering and feature pipeline (100k candidate records → optimized Parquet).* | Python · FAISS · Parquet |
| **[PatentLens](https://github.com/ArshvirSk/PatentLens)** | Prior-art patent search with a custom inverted index, TF-IDF and multi-zone scoring over 5,000 patents, evaluated with MAP / P@K / R@K. | Python · Flask |
